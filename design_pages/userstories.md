## User Stories
Example: “As a [user role], I want to [do something] so that I can [achieve a goal].”

### Admin User

As an Admin User I would like to manage user accounts so that my clients and collaborators don’t have to and I can view the application as if I was logged in to their user account.

### Producer User

As a Producer, I want to login and view all the projects in progress at a glance and quickly see what the next steps are for each project.

As a Producer, I want to login and view all the projects’ invoice progress at a glance and quickly see what invoices need to be sent out, what invoices are overdue and overall the income coming into my production company.

As a Producer, I want to create a project and have it automatically populate with tasks, events, and deliverables based on what kind of project it is so that I can save time managing the project.

As a Producer, I want to update the status of my project as it progresses by checking off tasks, events, and deliverables.

As a Producer I want to share the status and notes on specific deliverables with other collaborators such as Editors so that we are on the same page on the progress of the delivered video.

As a producer, I want my client to see a shooting schedule when they log in to the app and collaborate with me and my team on interview subjects, shoot times, locations, and action shots.

As a producer, I want my client to see the status of their project including their deliverables and provide feedback and approval for each video so that we are on the same page.

### Client User

As a client user I want to easily view the progress on our project and provide feedback in a painless and easy manner.

As a client user I want to view and edit shooting schedules and other shared communication quickly and easily.

Bonus, as a client user I can view invoices and make payments.

### Editor User

As an Editor I want to easily view all the projects assigned to me as well as update their status and provide notes as needed in a quick and pain free manner.

As an Editor I want to easily view all the invoices and payments relating to the video projects I have worked on.
