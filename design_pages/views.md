## Views

The following is a start to some of the views incorporated in to the application based on the original materials reviewed.  In addition to these views, basic CRUD views will be incorporated.

#### Projects Status View
A producer user can view all projects at different progress stages mimicking the original Trello board.

#### Projects Financials View
A producer user can view all the projects at different financial stages including information about invoices and payments.  Aggregated data for income and expenses.

#### Project Views - Client
A Client user can view the status of their project.  Submit feedback for completed videos.  Contribute and review shooting schedules.  View invoices

#### Project Views - Editor
An Editor can view all the video projects assigned them and can provide notes as well as update the status of each video project.
